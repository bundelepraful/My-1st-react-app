# My 1st React App 🚀

A simple **React Counter App** built with React and Vite. This is my first React project, created to practice React fundamentals such as components, state management, and event handling.

## ✨ Features

- ➕ Increase the counter value
- ➖ Decrease the counter value
- 🔄 Reset the counter to zero
- ⚡ Fast development using Vite
- 🎨 Simple and beginner-friendly UI

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Git and GitHub

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### 1. Clone the repository

```bash
git clone https://github.com/bundelepraful/My-1st-react-app.git
```

### 2. Navigate to the project directory

```bash
cd My-1st-react-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to use the application.
